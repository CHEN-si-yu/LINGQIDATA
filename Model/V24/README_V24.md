## 二、V24 设计 (与 V20 的差异只有「弱长周期辅助」)

1. **锐度主干与 V20 完全一致**: lin_1d/3d/5d 头 (同权重) + 顶部分支 1d主(a)/3d主(c)
   + checkpoint 选择 1d val_rankic — 不动冠军锐度来源。
2. **新增弱长周期辅助**: lin_10d/lin_20d 头 (RANK 权重 0.5/0.25 cons, 0.1/0.1 aggr
   ≈ 短周期的 1/8~1/4) + 顶部分支 10d 软Top 弱辅助 (TOP_AUX2 0.1/0.25)。
3. **打分组装**: ens24 = ens_w2 (V20 配方) + w·z(10d/20d 弱混合), w ∈ {0.1, 0.25, 0.5}
   由策略层扫描; w=0 即退化为 V20。
4. **种子/划分/超参 = V20 完全一致** → V20 vs V24 是干净因果对照。
