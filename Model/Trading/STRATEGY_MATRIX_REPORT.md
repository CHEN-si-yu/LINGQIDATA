## 四、结论要点

### 4.1 普适性 (任务3: 好的策略必须在大比例模型上超过基线)

- **排名退出族 (S4/S5/S8/S10) 是唯一"普适 + 收益"兼得的家族**: 超基线模型数
  19~20/24, 正收益 19~21/24, H1/H2 双正 11~16/24, 中位收益 +26.5%~+43.6%。
- **普适性最优 = S5 `re300_sl8_tr15_t2`** (U 0.865, 次高): **20/24 模型超过基线**
  (全场并列最高), 16/24 H1/H2 双正 (全场最高), 中位 +36.4%, 中位 MaxDD -22.3%。
  它同时满足任务要求的全部要素: 持仓2只 / 显式止损8% / 移动止盈15% /
  每晚最新打分评估持仓 (排名掉出300次日换仓) / 开盘先卖后买。
- S4 纯排名退出 (U 0.877, 最高) 中位收益更高 (+43.6%) 但 H1/H2 双正 14/24 略低;
  追求纯收益可选 S4, 追求均衡稳健选 S5。
- 其余家族 (固定持有/单仓/移动止损/利润锁定) 收益极端但普适性差:
  S1/S7 的 U 得分垫底 — 它们是"模型挑选型"策略 (对 V13/V11/V16 等少数模型爆发),
  不是普适策略。
