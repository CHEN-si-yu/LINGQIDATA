## 二、关键规律 (吸取教训)

1. **Top 锐度 ≠ IC**: 长周期标签提升广谱排序质量, 但把 top 分支主目标换成长周期
   会钝化「前 2 名」的选择锐度 — V21/V22/V23 三次独立复现。
2. **锐度来源**: 冠军的 Top 选择锐度来自 1d 主 / 3d 主 的顶部分支 + 短周期线性头
   集成; 这些必须保持主导地位。
3. **长周期的价值在别处**: V21/V22 证明 10d/20d 信号可以**稳定地**提高排序 IC —
   这是可用的「长板」, 只是不能让它主导 Top 选择。
4. **不同协议喜欢不同模型**: h20tr20_t2 吃 V20 锐度; S2_re300 吃 V22_20d/V23
   (0.82/0.99); D01 吃 V11 (2.61)。→ 多模型×多协议组合天然分散。
5. **稳定性 > 极值**: V20 h20tr20_t2 的 T2 +183% 单段集中; 组合目标应优先
   min(H1,H2)、三等分最小值、滚动窗正率, 而不是 cum 极值。

## 三、V24 设计原则 (取长补短)

**目标**: 保留 V20 的 Top 锐度, 吸收 V21/V22 的长周期 IC 长板, 稳定性优先。

1. **架构 = V20 不变的主干**: lin_1d/lin_3d/lin_5d 线性头 (ridge 热启动) +
   顶部分支主目标 **1d (族a) / 3d (族c) 不变** — 锐度来源原样保留。
2. **新增弱长周期辅助头**: lin_10d/lin_20d, 权重仅为短周期的 1/8~1/4
   (RANK_W10/W20 = 0.25~0.5 cons / 0.1 aggr) — 只作正则/纠偏, 不作主导。
3. **顶部分支辅助目标**: 10d 软Top, TOP_AUX_WEIGHT = 0.1~0.15 (弱辅助, 同 V20 的
   5d 辅助力度), 主目标权重与 V20 完全一致。
4. **checkpoint 选择不变**: val_rankic 仍按 1d (族a) / 3d (族c) — 保证选出的
   checkpoint 与锐度目标一致 (V21/V23 换主周期选择已被证明是钝化原因之一)。
5. **打分组装**: ens24 = z(V20 口径 mix) + w·z(10d/20d 弱混合), w ∈ {0.25, 0.5}
   在策略层扫描; 主成分 = 与 V20 完全相同的 (1,0.25,0,2)/(1,0,0,1)/wc=2 配方。
6. **评估 = 稳定性优先**: 排序指标改为 min(H1,H2,T1,T2,T3) 与 Sharpe、MaxDD,
   cum 仅作并列参考; 与 V20 同协议对照, 要求「更稳且不显著降收益」才升级。
7. **种子/划分/超参与 V20 完全一致** — 唯一变量是新增的弱长周期辅助 → 干净的
   因果对照 (V20 vs V24 的差异只来自长周期弱辅助)。
