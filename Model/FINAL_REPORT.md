## 三、三维评估方法 (本研究的核心方法论遗产)

## 五、研究结论总览 (封存口径, 勿再叠加)

> 读数注意: 本节 1~3 条及正文历史数字为**峰值口径下的研究史记录** (2026-09-06 前);
> 2026-09-06 种子检验 (§0.5.3) 后, 单种子策略层峰值的"代表水平"资格已被撤销 —
> 解释与实盘请以 §0.5 与 §0.4 的真实净值口径为准。

1. **历史冠军系统** (记录): ens_w2 打分 + hold5s8-收盘卖 (stop8%, 开盘买) — Test 净
   **+365.2%** (逐笔复利峰值口径), 需 ≈2× 资金; 开盘可执行真实口径见 §0.1~0.2。
2. **结构已收敛**: 任何第三组件 (V17 5d 族 / V18 GBDT 意图 / V21~V23 长周期与轨迹
   标签 / V24 弱长周期辅助) 、打分平滑均破坏冠军选股协同 — 均已数据验证为负或无效。
3. **V18 卡住是工程 bug 而非方向性结论**; V18/V19 已完成并转负结论证据 (见 §四)。
4. **种子纪律 (2026-09-06 新增, 最重要的可操作结论)**: 换训练种子 ≈ 换模型
   (Top1 Jaccard ≤0.11, 成交近零重叠); 单一种子的策略层峰值 (V20 +352%、
   V13 +538.7%) 均为高方差中奖, IC 层却对种子稳健 → 报数须用多种子中位/区间,
   实盘须用架构多样组合层 (iter5/6) 或 S6/S4 型低敏感协议 (稳定期望 ~+35~45%)。
5. **普适策略 (2026-09-06 新增)**: 跨 24 模型超基线最多的策略是排名退出族
   S4/S5 (19~20/24), 中位真实净值 +36~44% — 普适性来自架构多样性而非单一模型
   或单一策略的峰值。
