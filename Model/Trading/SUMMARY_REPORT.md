# 普适性交易策略研究总结 — V1~V20 全模型 × 开盘换仓引擎

> 日期: 2026-09-05 | 位置: `Model/Trading/` | 配套: `README.md` (使用说明)、
> `engine.py` (回测引擎)、`battery.py` (策略电池)、`results/` (全部结果)、`figures/` (图表)
>
> **一句话结论**: 在全部 V1~V20 打分结果上, 「Top2 双仓 + 排名退出(300) + 止损-8% +
> 移动止损-15% + 开盘先卖后买换仓」把隔日换仓基线的中位收益从 **+5.5% → +79.0%**、
> 正收益模型占比从 **16/24 → 19/24**、H1/H2 分半双正从 **4/24 → 16/24**,
> 且**全程只需 1 份资金** (旧 V20 冠军口径换仓日需 ≈2× 资金, 实测峰值占用 99,909 元)。

---

## 一、任务与要求还原

- 资金 **5W**; 允许持仓 **1~2 只**。
- **每晚收盘后**用当日因子数据推理打分 → 决策 **只作用于隔日开盘**。
- 换仓日**开盘同时卖出+买入** (卖出资金当日可用, 解决旧协议资金回笼问题)。
- **必须设计止盈止损**。
- 以**隔日换仓为 baseline**, 在 **V1~V20 全部现有打分结果**上衡量, 尽可能多尝试策略变体。

## 二、回测引擎 (`engine.py`) — 口径与设计

| 项 | 口径 |
|---|---|
| 决策 | 因子日 d 收盘打分 → 决策 → **d+1 开盘执行** (买入; 触发卖出同样在次日开盘) |
| 换仓/资金回笼 | 开盘**先卖后买**同一时点成交; 卖出资金当日用于买入; 每仓预算 = 5W/持仓数 |
| 持仓 | 1~2 只 (TopN, N∈{1,2}), 空位即时补入排名最高的未持有标的 |
| 止盈止损 | 收盘价触发 → **次日开盘**执行: 固定止损 / 固定止盈 / 移动止损(自峰值) / 利润锁定(ratchet) |
| 退出 | 固定持有期 hold; 排名退出 exit_rank (自适应持有, min_hold 保护); norep 续持; Top1 打分 expanding 分位择时(空仓) |
| 成本 | 佣金万2.5 (最低5元, 双向) + 印花税万5 (卖) + 过户费万0.1 (双向) |
| 执行真实性 | 整手100股; ST/退过滤; 一字涨停(≥9.5%)买不进 → 顺延下一候选; 一字跌停卖不出 → 顺延次日; 停牌无价 → 顺延 |
| T+1 | 当日买入当日不卖; (旧引擎"收盘卖"口径存在当日买当日卖瑕疵, 见§七) |
| 卖出口径 | `open` (本框架主口径) / `close_overlap` (旧冠军口径, 需双倍资金, 仅用于复现) / `close_seq` (收盘卖+次日开盘买) |
| 净值/指标 | 每日收盘市值净值 → 复利累计/年化/Sharpe(日频)/MaxDD; 逐笔净收益复利 (与旧引擎"净累计"口径一致); H1/H2 分半、T1/T2/T3 三等分 |

**引擎校准** (与 V11/strat_backtest.py 逐笔对齐, 含旧引擎 close-sell 变体):

| 锚点 | 旧引擎 | 本引擎 | 差异 |
|---|---|---|---|
| V11_ensw2 hold5s8 收盘卖 (旧冠军) | +365.17% | +364.69% | -0.48pp (仅期末强制清仓差) |
| V20_ensw2 hold5s8 收盘卖 | +277.79% | +277.40% | -0.39pp |
| V9_allz hold5s8 开盘卖 | +122.98% | +125.33% | +2.35pp (期末清仓差) |
| V2_allz 每日换仓 | -50.70% | -51.33% | -0.63pp |
| V9_allz 每日换仓 | +20.92% | +20.24% | -0.67pp |

## 三、数据与实验规模

- **24 个打分集**: V1~V17 `all_zscore_score` (16个) + V11 的 mixA/mixB/mixC/ens_w2 (4个)
  + V18 的 f1/f2 (LightGBM, 2个) + V20 `score_ens_w2` (1个) + V11 allz。
  (V19 无打分产物, 未纳入)
- 官方 Test 窗口: 因子日 20250901~20260901 (243 交易日), 价格数据至 20260904。
- **实验规模**: 4 个电池 + 追加组 = **272 个策略配置 × 24 集 ≈ 6,500 次回测**,
  另加稳健性矩阵 1,440 次, 合计 **≈8,000 次回测**。全部结果在 `results/`。

## 四、关键发现 (按策略家族)

**基线对比** (24 模型, 含成本):

| 策略 | 中位净收益 | 正收益占比 | H1/H2双正 | 中位MaxDD | 中位Sharpe | 交易数 |
|---|---|---|---|---|---|---|
| A01 隔日换仓 Top1 (基线) | +5.5% | 16/24 | 4/24 | -33.2% | 0.44 | 243 |
| D01 hold5+止损8% Top1 (V20式) | +23.3% | 17/24 | 10/24 | -27.7% | 1.00 | 50 |

1. **持有期 (hold)**: Top1 在 hold=5 最优 (中位 +28%), hold2 仅 +4% (成本/隔夜反转压制);
   Top2 随持有期延长单调改善 (hold20 → +71%), 但单一持有期对模型泛化差。
2. **止损**: hold5 口径下 **-8% 是甜点** (sl3% -3.1% / sl5% -4.7% / **sl8% +23.3%** /
   sl10% +18.3%), 与 V20 结论一致; 但过紧止损在排名退出族上会误杀大赢家 (V15: +136%→-19%)。
3. **固定止盈**: tp10~30% 触发极少、几乎不改变收益 (top1 持仓 5 日很难 +30%),
   **"落袋"应当用移动止损/排名退出实现, 而非固定目标价**。
4. **移动止损**: hold20+trail20% Top2 中位 +99.1%, 但正收益占比仅 17/24 (V17 -63%) —
   高收益、低普适。
5. **排名退出 (自适应持有) = 全场最优族**: Top2 + exit_rank 300~500 形成稳健平台
   (re300: 中位 +98.9%, 正收益 21/24; re500: +56.1%, 20/24)。收益来源 =
   让 Top1/2 的 3~5 日延续跑完、信号衰减(排名掉出前300)才走, 且对排名噪声有
   min_hold 与宽阈值双重容忍。
6. **择时**: 挂 daily 上 q0.3/0.5 空仓 73/116 天 → 负收益 (错过行情);
   挂在 h5_sl8 Top2 上 q0.3 → 中位 +44.9%、正收益 75%, 温和提升。
7. **Top2 > Top1**: 双仓分散显著提升普适性 (几乎每个家族), 与"信号集中第1名"并不矛盾 —
   第2名单独无 alpha, 但作为第1名的补充平滑了单票尾部风险。
8. **利润锁定 (ratchet)**: +20%锁+10% 中位 +15.6%; 加 sl8 后 +28.3% — 可用但弱于排名退出。

## 五、主推策略 (满足全部要求: 普适 + 资金回笼 + 止盈止损)

### 5.1 主推协议 `S2_re300_sl8_tr15`

```
持仓:  2 只 (Top2 等权, 每仓 2.5W, 整手)
买入:  每晚打分 → 次日开盘, 空位补入排名最高的未持有标的
        (ST/退、一字涨停、无价 → 顺延下一候选)
卖出:  收盘触发 → 次日开盘卖 (一字跌停/无价 → 顺延):
       ① 止损:  收盘价 ≤ 买入价 × (1-8%)
       ② 止盈:  收盘价 ≤ 持仓期最高收盘 × (1-15%)   [移动止损=动态止盈]
       ③ 退出:  最新打分排名 > 300 且已持有 ≥ 2 个交易日
换仓:  开盘先卖后买, 卖出资金当日闭环, 全程仅需 1 份资金 (5W)
```

**跨 24 模型表现** (含成本, 开盘口径):

| 指标 | 值 |
|---|---|
| 中位净收益 | **+79.0%** (均值 +92.7%) |
| 正收益模型 | **19/24** (79%) |
| 胜过隔日换仓基线 | **22/24** |
| 胜过 V20式 hold5s8 | 16/24 (旧协议在自己的 8 个模型上仍最优) |
| H1/H2 分半双正 | **16/24** (并列全场最高) |
| 中位 MaxDD | -17.0% (基线 -33.2%) |
| 中位 Sharpe | 1.33 (基线 0.44) |
| 交易数 / 平均持有 | ~80 笔 / 6.1 交易日 |
| 成本拖累 | 3.9% (基线 23.4%) |
| 资金闲置 (现金/净值) | 中位 16.7% (双仓整手取整) |
| 1W 资金口径 | 中位 +66.8% (最小佣金下仍稳健) |
| 最差模型 | V5_allz -36% (其余最差 -26%~-19%) |

逐模型明细与基线对比见 §九 表 3, 净值曲线见 `figures/fig4_universal.png`。

### 5.3 每日操作流程 (实盘手册)

1. **收盘后 (15:00~晚间)**: 跑模型打分 → 全市场截面排名 (z-score 口径, 962 只池)。
2. **决策 (当晚)**:
   - 持仓股: 若 ①收盘 ≤ 买入价×0.92 或 ②收盘 ≤ 持仓期最高收盘×0.85 或
     ③排名 > 300 (持有≥2交易日) → 列入次日开盘卖出单。
   - 买入: 若空位 > 0, 按排名顺序取未持有的前 2 只 (跳过 ST/退/一字涨停), 各 2.5W 整手。
3. **次日开盘 (9:30)**: 先卖后买同步完成; 跌停卖不出/涨停买不进 → 顺延次日重复。
4. **资金**: 5W 单账户即可, 换仓日无需额外资金 (旧协议需要 ≈2×)。

## 七、卖出口径与资金回笼问题 (本次研究的核心修正)

旧冠军协议 (hold5s8-收盘卖): **换仓日开盘买入下一轮 → 当日收盘卖出上一轮** —
开盘买入时旧仓资金尚未回笼, 需要 **≈2× 资金**。本引擎实测: V11_ensw2 旧口径下
同时占用资金峰值 **99,909 元** (≈2×5W), 且隐含"当日买入当日卖出"的 T+1 违规
(收盘卖出包含当日开盘新买的份额)。

| 口径 (h5_sl8, 24模型) | 均值净收益 | 正收益 | 峰值资金需求 | 备注 |
|---|---|---|---|---|
| `close_overlap` 旧冠军口径 | +62.7% | 17/24 | **99,909元 (2×)** | 不可用 5W 单账户执行 |
| `open` **本框架口径** | +49.7% | 17/24 | **50,000元 (1×)** | 先卖后买, T+1 合规 |
| `close_seq` 收盘卖+次日买 | +28.0% | 19/24 | 50,000元 (1×) | 资金安全但错过开盘延续 |

**开盘口径只损失 ~13pp 均值, 换回: 单账户可执行 + T+1 合规 + 资金当日闭环。**
对排名退出族, 开盘口径优势更大 (N2_re300: open +98.9% vs close_seq +52.4% —
开盘卖保留了信号衰减后的"隔夜延续"收益)。图表见 `figures/fig3_sellmode.png`。

| 维度 | N2_re300 | S2_re300_sl8_tr15 | 结论 |

| 无成本 | +113.8% | +92.1% | 成本拖累小 (3~4%), 优势非成本套利 |
| 无涨跌停/ST过滤 | +87.5% / 22正 | +94.6% / 20正 | 对过滤不敏感 |
| 1W 资金 | +48.1% / 20正 | +66.8% / 17正 | 最小佣金下仍显著为正 |

**风险提示**: ① 结论基于单一样本外窗口 (2025-09~2026-09), T3 段信号衰减明显,

③ 9.5% 涨跌停阈值对 20% 板块 (创业板/ST) 是近似; ④ 未计冲击成本 (5W 规模影响小)。
