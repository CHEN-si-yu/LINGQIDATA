## 一、策略定义 (10W 本金 = 两个独立 5W 资金池, 互不借贷)

### 慢腿 (5W): `u_h20_re300_tr15` — Top2 双仓, 每仓预算 = 池净值/2 (滚动再投资)

- 买入: 每晚收盘打分 → 次日开盘买入排名前 2 且未持有的标的 (每只整手 100 股,
  每仓目标 = 资金池净值/2; ST/退/一字涨停/无价 → 顺延下一候选)。
- 卖出 (收盘触发 → 次日开盘执行; 买入当日不评估; 任一触发即卖; 一字跌停/无价
  → 顺延次日继续):
  1. **排名退出**: 已持有 ≥ 2 个交易日 且 最新打分全市场排名 > 300 → 卖。
  2. **移动止盈**: 收盘价 ≤ 持仓期最高收盘价 × 0.85 (回撤 15%, 最高收盘每日更新,
     仅用收盘价序列) → 卖。
  3. **到期**: 持有满 20 个交易日 → 卖。
- **无固定止损** (此族叠加 sl8 经测不改善反鞭打; 止盈止损职责 = 规则 1 + 2)。
- 卖出后空位当晚按最新打分补入 (同上过滤), 次日开盘先卖后买, 资金当日闭环。

### 快腿 (5W): `D01` — Top1 单仓 (模型固定 V11_ensw2, 本文件冻结期内不换)

- 买入: 每晚 V11_ensw2 打分 Top1 → 次日开盘满仓整手买入。
- 卖出 (收盘触发 → 次日开盘执行): ① 收盘 ≤ 买入价 × 0.92 → 卖; ② 持有满 5 个
  交易日 → 卖。卖后同日开盘全仓换入当晚 Top1 (过滤/顺延同上)。

### 引擎参数 (engine.py 官方口径, 与回测完全一致)

```
慢腿: top_n=2, hold=20, exit_rank=300, min_hold=2, trail_pct=0.15
快腿: top_n=1, hold=5, stop_loss=0.08

口径: 开盘先卖后买 / 1 份资金 / 含成本(佣金万2.5min5+印花万5卖+过户万0.1)
      / 整手 / T+1 / ST·涨跌停·停牌过滤 / cum_net 真实净值(利润再投资)
窗口: 因子日 20250901~20260901 (243 交易日)
```
