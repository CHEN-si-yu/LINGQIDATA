## 一、V1.X 实验总结与 V2.X 设计动机

V1.X 系列通过 7 个模型的对照实验，得出了三个核心发现：

| 发现 | V1.X 证据 | 效果 |
|------|-----------|------|
| **D1: 预测周期是最强杠杆** | V1.4→V1.7 IC 单调递增 | 10d IC=0.0966 vs 1d IC=0.0506 (+91%) |
| **D2: 更长训练历史显著提升** | V1.3 vs V1.2 全维度领先 | 夏普 +33%, Top Ret Std +29% |
| **D3: 全量因子在 IC 维度更优** | V1.2 vs V1.1 IC +9% | 但策略层面差异不大（边际收益递减） |

基于以上发现，V2.X 系列的设计逻辑是：

1. **V2.1**: 将 D1 + D2 + D3 组合，验证叠加效果（4年窗口 + 10d目标 + 全量因子）
2. **V2.2/V2.3**: 在最优配置基础上探索因子质量过滤的效果
3. **V2.4**: 改进验证集切分方式，消除滚动窗口带来的训练分布不一致问题

## 三、V2.2 — 因子质量过滤（严格：NaN > 30% 剔除）

### 3.1 设计理念

V1.2 使用全量 953 因子，其中部分因子可能存在严重的数据缺失。如果某个因子的 NaN 占比超过 30%，说明该因子：
- 覆盖的股票/时间范围不足
- 数据源不稳定
- 实际可用信息量低

将这些"稀疏因子"提前剔除，可以减少模型需要处理的噪声维度。

### 3.2 过滤逻辑

```python
# 在加载因子数据后，训练前执行
factor_cols = [c for c in params.all_data.columns if c not in ['date', 'Code']]
nan_rates = params.all_data[factor_cols].isnull().mean()
keep_factors = nan_rates[nan_rates <= 0.30].index.tolist()
# 仅保留 NaN 率 ≤ 30% 的因子
params.all_data = params.all_data[['date', 'Code'] + keep_factors]
```

### 3.3 配置总览

| 配置项 | 值 | 与 V2.1 差异 |
|--------|-----|-------------|
| 预测目标 | label_ret_10d | 同 |
| 训练窗口 | 4年 | 同 |
| 因子集 | NaN ≤ 30% 的因子 | **新增过滤** |
| 预期因子数 | ~900-930 | 减少 20-50 个因子 |
| 验证切分 | 季度滚动 | 同 |

### 3.4 预期效果

| 对比维度 | V2.2 vs V2.1 |
|----------|-------------|
| 因子数 | 减少 ~3-5% |
| 模型容量需求 | 稍低（SE层输入维度略小） |
| 噪声水平 | 理论降低（移除极稀疏因子） |
| IC | 可能持平或略优（若被剔除因子确实无用） |
| 训练速度 | 略快（因子维度降低） |

### 3.5 实验假说

> **H2.2**: 剔除 NaN > 30% 的高缺失因子，可在不损失信号的前提下降低噪声维度，提升 IC 和策略稳定性。

## 四、V2.3 — 因子质量过滤（宽松：NaN > 90% 剔除）

### 4.1 设计理念

与 V2.2 形成对比实验。V2.3 采用更宽松的过滤阈值（90%），仅剔除极度稀疏的因子。这样做的逻辑是：

- 某些因子可能天然覆盖率低但信号极强（如特定行业/事件因子）
- 模型本身有处理缺失值的能力（通过 SE Recalibration 和特征 dropout）
- 过度过滤可能损失有价值的 niche 信号

### 4.2 过滤逻辑

```python
nan_rates = params.all_data[factor_cols].isnull().mean()
keep_factors = nan_rates[nan_rates <= 0.90].index.tolist()
# 仅剔除 NaN 率 > 90% 的极端稀疏因子
params.all_data = params.all_data[['date', 'Code'] + keep_factors]
```

### 4.3 配置总览

| 配置项 | 值 | 与 V2.1 差异 |
|--------|-----|-------------|
| 预测目标 | label_ret_10d | 同 |
| 训练窗口 | 4年 | 同 |
| 因子集 | NaN ≤ 90% 的因子 | **极度宽松过滤** |
| 预期因子数 | ~945-950 | 减少 < 10 个因子 |
| 验证切分 | 季度滚动 | 同 |

### 4.4 预期效果

| 对比维度 | V2.3 vs V2.1 | V2.3 vs V2.2 |
|----------|-------------|-------------|
| 因子数 | 几乎相同 | 多 ~20-50 个 |
| 信号保留 | 几乎完整 | 更多 niche 信号 |
| 噪声水平 | 几乎相同 | 略高 |
| 实验意义 | 对照 V2.2 的阈值敏感性 | 确定最优过滤阈值 |

### 4.5 实验假说

> **H2.3**: 对比 V2.2 和 V2.3，可以确定最优的 NaN 过滤阈值。如果 V2.2 > V2.3，说明严格过滤有显著收益；如果接近，说明模型本身能处理缺失。

## 五、V2.4 — 固定时间窗口验证切分

### 5.1 V1.X 验证方式的问题

V1.X 的验证集切分方式：

```
每个季度独立训练:
  测试集: 当前季度 (e.g., 2025Q3)
  验证集: 过去一年的对应季度 (e.g., 2024Q3)  ← 每个 fold 不同!
  训练集: 验证集之前 2-4 年的数据
```

**问题**：不同 fold 的验证集来自不同时间段，训练数据的时间分布也不一致。这导致：
- 各 fold 之间的模型不可直接比较
- 验证集的时间漂移可能被误认为是过拟合
- 4-fold ensemble 时各 fold 学到的分布不同

### 5.2 V2.4 的新切分方式

```
固定训练窗口: 测试开始前 5 年 → 测试开始前 1 年（固定 4 年）
验证集: 从训练窗口中随机抽取 1/4 的日期
4个Fold: 所有 fold 共享同一训练时间范围，仅验证集随机种子不同
```

```
时间线:
|---- 4年训练窗口 ----|---- 1年gap ----|-- 测试季度 --|
   past-5yr          past-1yr        test_start
   
   ← 随机抽 1/4 做 valid（每 fold 不同 seed）
   ← 剩余 3/4 做 train
   ← 4 个 fold 共享同一时间范围
```

### 5.3 实现关键代码

```python
def get_train_date_split(kfold, date_list, season, period, interval=10, month=48):
    # 固定 4 年训练窗口
    train_end_dt = test_start - relativedelta(years=1)
    train_start_dt = train_end_dt - relativedelta(years=4)
    train_date_list = [选入训练窗口的所有日期]
    
    # 随机 1/4 做验证集
    random.seed(args.seed + period)  # 每 fold 不同 seed
    valid_date_list = random.sample(train_date_list, len(train_date_list) // kfold)
    
    # 从训练集中移除验证日期
    train_date_list = [排除 valid 后的日期]
```

### 5.4 配置总览

| 配置项 | 值 | 与 V2.1 差异 |
|--------|-----|-------------|
| 预测目标 | label_ret_10d | 同 |
| 训练窗口 | 固定 4 年 | **不再滚动** |
| 因子集 | 953 全量 | 同 |
| 验证切分 | **随机 1/4，固定时间窗口** | **核心差异** |
| shuffle_split | True | 改为 True |

### 5.5 预期效果

| 对比维度 | V2.4 vs V2.1 |
|----------|-------------|
| 训练分布一致性 | ✅ 所有 fold 共享同一时间范围 |
| Fold 间可比性 | ✅ 验证集来自同一分布的不同随机子集 |
| 过拟合检测 | ✅ 更准确的验证信号 |
| 潜在风险 | 验证集与训练集时间重叠（但无数据重叠） |

### 5.6 实验假说

> **H2.4**: 固定时间窗口 + 随机切分能产生更一致的验证信号，各 fold 的 val_wei 差异应显著小于 V1.X 的滚动窗口方案。
