## 3. 关键发现与路径

1. **数据侧诊断 (决定性)**: 对 848 个因子逐日截面 rankIC 分析发现: 波动率/价差/日内极值类因子
   训练期 IC 高达 0.11 (IR 0.9); 标签核实为真实前瞻收益 open[T+2]/open[T+1]-1, 无泄漏。
2. **信号是线性的**: 600 天截面秩岭回归 (无训练) 在 Test 上即得 RankIC=0.0535/IR=0.336 —
   超过 V2-V5 全部深度 MLP → 深网络在稀释信号。
3. **V6 转折点**: 线性排序头 (岭热启动) + 独立小 MLP 顶部分支 (有界排序损失: 软Top收益+ListNet),
   打分 = z(线性) + z(顶部)。所有指标同步创新高。
4. **风格权衡**: 激进损失 (Top1 强/IC 弱) 与保守损失 (IC 强/Top1 弱) 客观存在 → 跨风格集成。
5. **V9 集成方案 (用户建议)**: 同一季节目录下 4 个保守风格折 + 4 个激进风格折,
   analysis.py 原生的 8 模型 z-score 求和集成 → 同时保住 IC (+0.044) 与 Top1 (+55%)。
6. 其他有效组件: 特征/标签截面秩高斯化 (V4), 时间衰减加权 (hl=600d), R-Drop, AdamW+cosine+早停,
   ListNet 除以 log(n) 归一化, 岭初始化排除验证池 (V7, 更干净)。

## 4. 最优版本 (V9) 技术规格

- 路径: `/autodl-fs/data/lingqiData/Model/V9/` (结果: `V9/model_pic/output.md`)
- 特征: 848 因子截面秩高斯化 (train/inference 一致, 未动因子层)
- 结构: 线性排序头 lin_1d/lin_5d (岭热启动) + 独立小 MLP 顶部分支 (848→128→64→1)
- 打分: z(lin_1d) + z(top); 集成: 8 模型 (4保守+4激进) z-score 等权求和
- 保守风格: RANK_W1=4, TOPRET=0.3, LISTNET=0.1; 激进风格: RANK_W1=0.5, TOPRET=2.0(τ=0.03σ), LISTNET=0.6(K=10)
- 损失全有界 (秩高斯标签), R-Drop 0.1, 时间衰减 hl=600d, AdamW + warmup + cosine, 早停 patience=10
