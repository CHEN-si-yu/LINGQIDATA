## 二、实盘每日协议 (5W 账户)

1. 每日收盘后: V11a 与 V11c 各自增量推演 (analysis.py), 更新 heads
2. 构建 ens_w2 打分 = z(mixA) + 2·z(v11c_top), 取最新一天
3. 决策 (hold5s8):
   - 空仓 → 次日开盘买入 Top1 (整数手, ~5W)
   - 持仓满 5 个交易日 → 次日开盘卖出并买入新 Top1
   - 持仓期收盘价较买入价 ≤ -8% → 次日开盘止损卖出 (再寻新 Top1)
   - 其余情况持有不动 (T+1 合规)
4. 成本: 佣金万2.5(最低5元) + 印花税万5(卖) + 过户费万0.1; 周频换手成本影响小
5. 风险: 单票满仓; 历史 MaxDD -14.3%; 用闲钱, 严格按信号执行不主观干预

**最新信号 (20260903 收盘)**: ens_w2 Top1 = 中科三环 (9/4 开盘买入, 持有至 9/10 开盘)

## 三、V11 迭代核心发现

1. **成本是 5W 账户最大敌人**: 日频换手 243 次吃掉 24.7pp (毛 62.5%→净 27.0%)
2. **止损+延长持有** 是策略层主杠杆; stop5% 过紧会鞭打, 8% 最优
3. **多目标 (3d 头) 显著提升 regime 稳健性**: V9 系策略 H2 全部转负,
   V11a mixA / V11c 组合在两半均正
4. **norep+hold3 ≡ 跟随 Top1 的自适应持有**: 收益来自 Top1 的 3d 延续 (lin_3d 头),
   非省成本 (Top1 连续段均值仅 1.04 天)
5. **策略层与 IC 层的最优 mix 权重不同**: 需按用途分别选
6. **跨版本集成 (V11a 1d 顶部 + V11c 3d 顶部) 互补两半区间** → 冠军 ens_w2
