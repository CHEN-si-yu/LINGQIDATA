> **生成日期**: 2026-06-25  
> **分析范围**: `/autodl-fs/data/lingqiData/Model/V0.1` / `V0.2` / `V0.3` 全量对比  
> **核心指标**: **IC**（预测排序能力）、**ICIR**（信息系数稳定性）、**Top_Return**（选股超额收益）  
> **数据来源**: `model.py` 源码、训练日志 (fit/test fold1-4)、各版 `analysis.ipynb` 回测输出  
> **模型总数**: **3 个独立模型**（V0.1: fac_all 960因子, V0.2: fac_IC_top500 500因子, V0.3: fac_all 960因子 + 个人ALL-IN模式）

## 一、实验总览：三版的目的与结论

### 1.1 V0.1 — fac_all 全量因子（机构组合基线）

**目的**：以 V6.7 宽架构 + 多周期联合训练为模型主体，使用全量 960 因子训练，机构组合模式（Top-500, 1.5B）回测，建立基线。

| 模型 | 核心设计 | 结论 |
|------|---------|------|
| V0.1 | fac_all (960因子) + MLP-Wide (512→256→64→3 Heads) + 机构组合 | **IC=0.0523, ICIR=0.6090**，泛化效率最优，全面均衡 |

> **结论：V0.1 是稳健的机构级基线。** IC=0.0523、ICIR=0.6090 均为三版中最高或接近最高，val→IC 转化效率最优（0.0321），说明全量因子 + 机构组合模式在预测能力和稳定性上达到了良好平衡。

### 1.2 V0.2 — fac_IC_top500 精选因子

**目的**：在 V0.1 基础上，将因子集从全量 960 缩减为按 IC 排序取 Top 500，验证因子精简是否带来性能提升。

| 模型 | 核心设计 | 结论 |
|------|---------|------|
| V0.2 | fac_IC_top500 (500因子) + 同 V0.1 架构 + 机构组合 | **IC=0.0486 (-7.1%)**，多策略收益全面垫底，val→IC 转化最差 |

> **结论：简单的 IC 排序筛选不是好的降维策略。** V0.2 在三版对比中持续垫底——IC 最低（0.0486）、多策略收益 0/6 胜出。500 因子相比 960 因子丢失了约 7% 的预测能力，且验证集过拟合最严重（val_wei 最高但 IC 最低）。

### 1.3 V0.3 — fac_all 全量因子 + 个人 ALL-IN 模式

**目的**：保持 V0.1 的模型架构和因子集，新增 **个人 ALL-IN 回测模式**（选预测值最高的 1 只股票满仓买入，隔日卖出），探索个人跟单场景。

| 模型 | 核心设计 | 结论 |
|------|---------|------|
| V0.3 | fac_all (960因子) + 同 V0.1 架构 + **个人ALL-IN模式** | **IC=0.0532 ✅，多策略 6/6 全胜 🥇，Top 1 年化 286.40%** |

> **结论：V0.3 是多策略回测的全场冠军。** 与 V0.1 使用完全相同的因子集和架构，仅因独立训练 + 个人 ALL-IN 回测模式，在所有 6 个策略上全面领先。IC (0.0532) 与 V0.1 (0.0523) 基本持平，但多策略年化收益大幅领先——V0.3 是当前最优的单模型选择。

## 二、模型结构与训练配置

### 2.1 神经网络架构（三版完全相同）

```
Input (N factors) → Linear(N, 512) + LeakyReLU + Dropout(0.2)
                  → Linear(512, 256) + BatchNorm + GELU + Dropout(0.1)
                  → Linear(256, 64) + BatchNorm + GELU
                  → ├─ Linear(64, 1) → pred_1d
                    ├─ Linear(64, 1) → pred_5d
                    └─ Linear(64, 1) → pred_10d
```

### 2.2 训练策略（三版完全相同）

| 超参数 | 值 |
|--------|-----|
| Batch Size | 8 × GradAccum 4 = effective 32 |
| Learning Rate | 0.0005 (base), OneCycleLR max=0.001 |
| Weight Decay | 3e-2 |
| Dropout | 0.2 (首层) / 0.1 (中间层) |
| Label Smooth | noise=0.02 |
| Time Decay | half-life=365天, ref=20260101 |
| Gradient Clip | 1.0 |
| SWA | enabled, start=0.6 epoch |
| Precision | bf16-mixed |
| Multi-Horizon Weights | 1d=1.0, 5d=0.5, 10d=0.3 |

### 2.3 训练/验证/测试划分（完全相同）

- **训练窗口**: 测试季度前 4 年
- **验证集**: 测试季度前 1 年，随机采样 1/4
- **测试集**: 目标季度全部交易日
- **季节覆盖**: 2026Q2, 2026Q1, 2025Q4, 2025Q3, 2025Q2, 2025Q1
- **Fold**: 4 折（不同随机种子划分验证集）

### 2.4 三版差异一览

| 维度 | V0.1 | V0.2 | V0.3 |
|------|------|------|------|
| 因子集 | `fac_all` (全量) | `fac_IC_top500` (精选) | `fac_all` (全量) |
| 因子数量 | **960** | 500 | **960** |
| 训练回测模式 | 机构组合 (Top-500, 1.5B) | 机构组合 (Top-500, 1.5B) | **个人ALL-IN** (Top-1) |
| GPU 设备 | CUDA_VISIBLE_DEVICES=0 | CUDA_VISIBLE_DEVICES=1 | CUDA_VISIBLE_DEVICES=0 |
| 分析回测模式 | 机构组合 | 机构组合 | 个人ALL-IN |

> ⚠️ **重要**: V0.3 在训练和分析阶段均使用了 **个人ALL-IN 回测模式**（选预测值最高的 1 只股票全仓买入，隔日开盘卖出）。这与 V0.1/V0.2 的机构组合模式（Top-500 流动性加权分配，15 亿资金模拟）在 `test_wei` 和 `top_return` 指标的数值上不可直接对比。但 **IC/ICIR** 和 **多策略回测** 结果是可对比的。

### 2.5 V0.3 新增特性：双回测模式

| 模式 | `personal` (个人ALL-IN) | `institutional` (机构组合) |
|------|------------------------|---------------------------|
| 选股方式 | 选预测值最高的 Top-N | Top-500 流动性加权分配 |
| 持仓数量 | 1 只（可配置） | 最多 500 只 |
| 资金规模 | 无约束 | 15 亿 |
| 流动性约束 | 无 | 按流动性加权 |
| 适用场景 | 个人投资者跟单 | 机构级组合管理 |

> 🔍 V0.3 默认使用 `personal` 模式，这是与 V0.1/V0.2 在训练阶段的关键差异——训练期间的 val_wei/test_wei 指标因回测模式不同而含义不同。

### 9.2 核心发现

**🔬 发现 1：V0.3 (fac_all + personal 模式) 在多策略回测中全面领先**

V0.3 在所有 6 个策略（Top 1/3/5/10/20 + 开盘红）上均取得了最高年化收益和最优 Sharpe 比：
- Top 1 年化 **286.40%**，较 V0.1 (+21.5%) 和 V0.2 (+32.2%)
- 开盘红 **275.49%**，比此前最优的 V0.2 高出 29.4%
- 这是 V0 系列中策略层面表现最强的单模型

**🔬 发现 2：IC 层面 V0.1 与 V0.3 基本持平，全量因子持续优于精选因子**

V0.1 (IC=0.0523) 和 V0.3 (IC=0.0532) 的预测能力差异在统计噪音范围内（<2%），均显著优于 V0.2 (IC=0.0486)。全量 960 因子相比 IC 精选 500 因子的信息优势得到再次验证。

**🔬 发现 3：不同训练 run 之间存在有意义的表现差异**

V0.1 和 V0.3 使用完全相同的架构、因子集和超参，仅因独立训练（不同随机种子/初始化）而产生表现差异。V0.3 在策略层面表现更强，提示**训练随机性**对最终模型质量有不可忽视的影响，建议考虑 ensemble 多个独立训练的模型。

**🔬 发现 4：V0.2 的风险控制优势值得关注**

尽管 V0.2 在收益层面落后，但其近期 10 日最大回撤 (-2.39%) 远优于 V0.3 (-9.59%) 和 V0.1 (-5.07%)，说明因子精简可能带来了更平滑的预测分布，降低了极端错误的风险。**V0.2 的低回撤特性在震荡市中可能具有独特价值。**

**🔬 发现 5：Personal ALL-IN 模式的高收益伴随高波动**

V0.3 的 personal 模式在大部分季度表现突出，但 2025Q4 出现负收益 (-30.6%)，表现出单票策略的"翻车"风险。机构组合模式通过分散化有效平滑了这种风险。

### 9.4 建议

1. **主力模型推荐 V0.3 (fac_all)**：在保持与 V0.1 相当的 IC 水平下，V0.3 的多策略回测表现全面领先，是当前最优的单模型选择

2. **个人跟单场景使用 personal 模式**：V0.3 的 Top 1 ALL-IN 策略年化 286%，个人投资者可直接跟单，但需承受较高的单日波动（最大回撤 -9.6%）

3. **机构场景考虑 V0.1+V0.3 ensemble**：两个独立训练的 fac_all 模型可以进行预测融合，有望进一步提升 IC 并降低方差

4. **关注 V0.3 的过拟合风险**：2026Q2 val_wei (2.18) 显著高于 V0.1 (1.63)，但全季 IC 基本持平，提示需要对 V0.3 进行更长时间窗口的 out-of-sample 检验

5. **开盘红策略强烈推荐 V0.3**：275.49% 年化收益是当前最优，可作为独立策略线运行

6. **因子筛选策略建议重新评估**：V0.2 (IC Top 500) 在三版对比中持续垫底，简单的 IC 排序筛选不是好的降维策略。建议尝试：
   - 正交化筛选（剔除高相关冗余因子）
   - 按 ICIR 替代 IC 排序
   - 保留部分低 IC 但低相关性的因子（增量信息）
   - 或直接使用全量因子 + 更强的正则化（如增大 dropout）

7. **下一步实验方向**：
   - **V0.4 候选**: 多 run ensemble（如 3 个独立训练的 fac_all 模型融合）
   - **V0.5 候选**: 尝试 600-800 因子的中间维度，平衡信息量与过拟合风险
   - **V0.6 候选**: 在 personal 模式基础上增加风险控制（如最大回撤止损、波动率目标仓位）
