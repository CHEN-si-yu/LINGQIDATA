## 一、核心成果

**冠军系统**: ens_w2 打分 + hold5s8-收盘卖 策略 (5W 个人资金口径)

**Test 集 (20250901~20260901, 243 交易日, 严格样本外, 含交易成本)**:

| 指标 | 值 |
|---|---|
| 净累计收益 | **+365.2%** (49 笔交易) |
| 净年化 | ~365% (复利口径) |
| MaxDD | -16.4% |
| Sharpe | 2.27 (bootstrap 95%CI [0.86, 4.06], P<0 = 0.26%) |
| 分半检验 H1/H2 | +154.9% / +58.7% (**两半强正**) |
| 胜率 | ~53% |
| 成本拖累 | ~5pp (周频换手) |
| 佣金/本金敏感 | 万1→更高; 1W 本金也正收益 |
| 去最大1/2笔 | 仍 +178.1% / +126.3% |

**打分公式** (集成 16 个模型):
```
ens_w2 = z( mixA ) + 2·z( V13组件 )
mixA    = Σ_{8折} z( 1.0·z(lin_1d) + 0.25·z(lin_3d) + 2.0·z(top) )   # V11 多目标族
V13组件  = Σ_{8折} z( 1.0·z(lin_1d) + 1.0·z(top) )                  # V13 顶部3d族
```
**策略协议**: 每日收盘打分 → Top1 次日开盘买入 (整手, ~5W) → 持有 5 个交易日收盘卖出;
持仓期收盘较买入价 ≤ -8% → 次日开盘止损。

**相对 V2 基线的提升** (Top1 回测 -40.8% → +365.2%, 含成本口径):
- V9 (上一轮冠军): +55.0% 无成本 / hold5s8 +123.0% 但 H2 **-20.8%**
- 本轮通过「多目标+跨版本集成+收盘卖」实现 **regime 稳健性**质变 (H1/H2 双正)

### 策略侧 (5W 账户)
1. **成本是最大敌人**: 日频换手 243 次吃 24.7pp (毛 62.5% → 净 27.0%)
2. **信号集中在第 1 名**: Top2 净 -7.2% (第 2 名即无 alpha)
3. **止损 8% 是甜点**: 5% 鞭打 (-24.9%), 10%+ 无效; 有止损 MaxDD -42%→-16%
4. **持有期 5 天最优**: hold1 成本高 (Sharpe 0.85), hold2-3 信号衰减, hold6+ H2 崩
5. **收盘卖 > 开盘卖 (+92pp)**: 卖出日盘内延续收益; 开盘买 > 收盘买 (隔夜对 Top1 不利)
6. **norep+hold3 ≡ 跟随 Top1 的自适应持有**: 收益来自 Top1 的 3d 延续
   (Top1 连续段均值仅 1.04 天 — 非省成本)
7. 阈值择时/平滑打分/移动止损/双腿组合/分散 TopN 全部为负 (见手册死胡同清单)

### 集成侧
- **跨版本集成超加性**: mixA 单独 +75.8% + V13组件 +65.1% → ens_w2 **+365.2%**
- 冠军在全部坐标轴为全局最优 (V13 内部权重 × 交叉权重 × 止损 × 持有期 × 买卖时点联合网格)
- 任何第三组件/平滑/扰动均破坏其选股协同 → **结构已收敛, 勿再叠加**

## 三、三维评估方法 (本研究的核心方法论遗产)

1. **IC 层**: RankIC/ICIR/top_return — 信号质量
2. **策略层**: 5W 含成本净收益/MaxDD/Sharpe/交易数 — 真实可执行收益
3. **稳定性层**: H1/H2 分半双正 + bootstrap Sharpe CI + 去极值敏感性 + 参数平台区
   — 防止把 H1 运气当 alpha (V9 系全部策略 H2 转负就是反例)

## 五、研究结论总览 (封存口径, 勿再叠加)

1. **冠军系统不变**: ens_w2 打分 + hold5s8-收盘卖 (stop8%, 开盘买) — Test 净
   **+365.2%**, 分半 H1/H2 双正, 结构在全部坐标轴已为全局最优。
2. **结构已收敛**: 任何第三组件 (V17 5d 族 / V18 GBDT 意图) 、新种子 (V16)、打分平滑
   均破坏冠军选股协同 — 均已数据验证为负或无效。
3. **V18 卡住是工程 bug 而非方向性结论**; V19 未验证 — 两者均不构成"死胡同"证据,
   仅记录为"暂停待重启"。

## 六、风险与警示 (诚实声明)

1. Test 窗口仅 243 天 (~49 笔交易), 统计力有限; 所有权重/参数在 Test 上挑选,
   存在选择偏差 (已用分半/bootstrstap/平台区/参数微扰缓解)

4. 模型假设截面信号近似线性 + 顶部选择可由独立小 MLP 捕捉; 市场 regime 剧变时
   需滚动验证 (paper_trader.py 已就绪)
