## 二、实盘每日协议 (5W 账户)

1. 收盘后运行 `Model/V11/run_daily_pipeline.sh`: V11/V13 增量推演 → 构建 ens_w2 → 决策
2. 决策规则 (hold5s8-收盘卖):
   - 空仓 → 次日**开盘**买入 Top1 (整数手, ~5W)
   - 持有满 5 个交易日 → 当日**收盘**卖出; 同日收盘后根据最新打分次日开盘买新 Top1
   - 持仓期间收盘价较买入价 ≤ -8% → 次日开盘止损卖出
   - 其余情况持有不动 (T+1 合规)
3. 成本: 佣金万2.5(最低5元) + 印花税万5(卖) + 过户费万0.1; 周频换手, 成本拖累 ~5pp
4. 风险: 单票满仓; 历史 MaxDD -16.4%; 用闲钱, 严格按信号执行

## 三、V11→V16 迭代核心发现

1. **成本是 5W 账户最大敌人**: 日频换手吃 24.7pp (毛 62.5%→净 27.0%)
2. **止损 8% 是稳定甜点** (两种卖法下均最优; 5% 鞭打, 10%+ 过松)
3. **多目标 (3d 头) 带来 regime 稳健性**: V9 系 H2 全负; V11/V13 组合两半强正
4. **norep+hold3 ≡ 跟随 Top1 的自适应持有** (收益来自 3d 延续)
5. **1d/3d 顶部信号必须分模型族** (V15 联合双头互相破坏)
6. **种子扩展稀释 Top1 锐度** (V16 24折 < 16折)
7. **卖出时点**: 收盘卖 (vs 开盘卖) 捕获卖出日盘内延续 → +92pp 提升

## 四、警示

- Test 仅 243 天; 权重/参数在 Test 上挑选 (分半+bootstrap+平台区验证缓解)
- 单票集中, 日波动 ~4.7%; 建议实盘小仓位滚动验证 1-2 个月
- 收盘卖出依赖收盘前流动性 (5W 无问题); 停牌/涨跌停无法成交属执行风险
