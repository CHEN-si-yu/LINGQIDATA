# IC 迭代优化过程记录（2026-08-13 启动）

目标：验证集平均 IC > 0.1（8h 内），从模型层与因子层两个层面入手。

## 一、诊断结论（基于 V6.1 全链路审计 + 实测）

### 实测数据（我直接跑的数据，非二手结论）
1. **因子侧天花板**（768 因子 vs label_ret_10d，全样本逐日截面 rankIC）：
   - 最强单因子 amplitude_20：mean IC 0.071 / mean|IC| 0.176
   - turnover_20 0.062、smart_money_share -0.070、amihud_intraday -0.074、margin_velocity -0.072
   - 全部因子 ICIR 仅 0.24~0.52（方向不稳定）
   - 因子矩阵干净：中位缺失率 0.4%，最差 19.9%
2. **V6.1 模型验证 IC**（4 fold 日志）：Pearson IC 0.0378~0.0662，均值 0.0486，从未超过 0.0662
3. **label 问题**（我实测）：
   - label = open[t+1+N]/open[t+1]-1，用 daily_adj.parquet 计算
   - daily_adj 是"减常数"式伪复权（69% 股票 raw-adj 严格恒定），出现负价格、3d label 最低 -121% 等垃圾值
   - broken vs clean（原始价重算）label 逐日截面 spearman = 0.987（排序结构基本保留）
   - 但 broken label 波动率被放大 75%（std 0.165 vs 0.094），极端值 3 倍
4. **训练管线缺陷**（V6.1）：
   - data_end_date=None → 验证池包含 2026-07/08 回测窗（选模泄漏）
   - 时间衰减 half-life=365d ref=20260101 → 2020 年数据权重仅 1.6%，有效训练数据≈2024-2025
   - OneCycleLR 峰值 ep18，早停在 ep14-20 → 从未退火
   - SWA 起点 0.6×60=ep36 → 从未生效
   - 只算 Pearson IC，RankIC/ICIR 从未算过
   - label 不缩尾、涨停不可买入股票进训练/评估（纸面 IC 虚高）、停牌 fillna(0)
   - R-Drop MSE 权重 0.5 与排序目标不协调

### 结论：IC~0.05 的瓶颈主要在「弱因子信号 + 高噪 label + 训练管线缺陷」；
模型本身能拟合（train loss→-0.15），不欠拟合。目标 0.1 需从 label 清理、
评估口径、训练窗口三方面先修，再试模型结构。

### 环境约束（重要）
- **内存 >120G 会被系统 KILL（用户确认）**。4 fold 并行 + 数据加载瞬时峰值容易触碰。
- 4 次运行都在 fold1 ep14 / fold2-3 ep15 / fold4 ep14（≈训练 9-12 分钟）处进程消失、日志无 traceback、cgroup oom_kill=0。
- 已排除：cgroup OOM（watcher 实测死亡时 cgroup 仅 36G）、会话清理（setsid 完全脱离仍死）。
- 正在验证两个假设：(A) 平台对 CUDA 进程有 ~10min 时间限制（claude 用户 vs root 对照测试运行中）；(B) 数据加载瞬态内存尖峰超 120G（4-fold 并行时）。
- 应对预案：训练改 root 运行；或 2+2 串行 fold；或断点续训循环（每 ~10min 被杀后从 checkpoint 恢复）。

### 环境问题定位（已确认）
- CUDA 最小测试进程（claude 与 root 各一）存活 10+ 分钟 → 排除"CUDA 进程 10min 时限"假说。
- 结合用户确认（4 fold 并行峰值约 110G，超 120G 被杀）：**训练死亡 = 内存瞬态峰值**。
- 对策：**2+2 折并行**（每对峰值 ~55-60G，安全）；每轮只用 2 fold 快速筛选，最终版再 4 fold 验证。

- 训练同口径对照（winsor+fillna0，与各折验证日志可比）：1d=0.0632 / 5d=0.0919 / 10d=0.1047 / 20d=0.1284，与干净口径几乎一致。

- 弱月（202605~202606）集中出现 → 非随机波动，更可能是市场风格切换（流动性/小盘风格），说明 4 头信号在风格切换期协同失效。
- 收敛：单折 per-fold avg 0.0915~0.0986 与集成四头平均 0.0971 几乎一致 → 4 折集成对平均 IC 的增益有限（≈0.003），提升主要来自 fold3 重训（+0.025）。

**系列总结（V6.2→V6.9）**：0.0486（V6.1 基线）→ 0.073（管线修复+宽度）→ 0.083（51 新因子）→ 0.086（40 因子 2 折）→ 0.097（4 头 + 4 折集成）。路径：**因子增量（+0.013）+ 多头架构（+0.011）> 集成（+0.003）> 中性化（0）**。0.1 目标未达成，差距 ~3%，主要被 1d 短板与 202605-202606 风格切换期拖累。
